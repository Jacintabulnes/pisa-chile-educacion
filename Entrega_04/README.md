# Entrega 04 — Proyecto PISA Chile

## Proyecto
Cuando las brechas se achican, pero no todos avanzan

## Descripción
Esta entrega reúne las crónicas y visualizaciones individuales sobre las brechas de comprensión lectora en Chile, elaboradas a partir de los resultados PISA.

## Integrantes
- Análisis de brecha de género
- Análisis de brecha socioeconómica

## Contenido
Las carpetas individuales incluyen las crónicas, visualizaciones, códigos y bases de datos utilizadas.
