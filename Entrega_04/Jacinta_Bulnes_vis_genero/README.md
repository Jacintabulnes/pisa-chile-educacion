# Entrega individual — Brecha de género en comprensión lectora

## Tema
Evolución de las diferencias de comprensión lectora entre hombres y mujeres en Chile, a partir de los resultados de PISA.

## Crónica periodística
La brecha de lectura entre hombres y mujeres volvió a crecer, pero Chile sigue retrocediendo.

## Ver crónica publicada
https://jacintabulnes.github.io/pisa-chile-cronica-genero/

## Repositorio de la crónica

## Visualización
Gráfico de líneas elaborado con Python y Altair para analizar la evolución de los puntajes de comprensión lectora según género.
